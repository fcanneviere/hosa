# Hosa

## Installation et lancement

Prérequis : Python 3.10+

```bash
python run.py
```

Cela installe les dépendances (`hosa/app/requirements.txt`) puis démarre le serveur sur http://localhost:3000

Variables d'environnement optionnelles :
- `PORT` : port d'écoute (défaut `3000`)
- `HOSA_KB_ROOT` : chemin vers la base de connaissances à servir
